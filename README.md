# boreal (Godot port) — MVP complete

Standalone Godot 4.7 port of the BOREAL survival sim (original TypeScript/three.js prototype: [podocarp/boreal-ts](https://github.com/podocarp/boreal-ts)).
**MVP review 2026-10-11: `docs/MVP-REVIEW.md` — full gate evidence (suite, CI
steps, fresh clone, web export + smoke, screenshots).**
**Phase 1 = pure sim core + analytic terrain, golden-value tested (frozen).
Phase 2a = explorable 3D world: real CC0 assets, terrain mesh + MultiMesh
scatter, third-person player. Phase 2b = playable loop (GameLoop drives the
sim on a fixed 0.25 s accumulator), survival HUD, stream water shader,
flat-ground camp, day/night lighting. Phase 2c (partial) = snares/fishing/
injuries ported from dangers.ts; wolves deliberately CUT from the MVP
(owner directive 2026-10-10: tension is solo + slow environmental death;
snares are a food source, never a hazard).**

## Layout
- `src/sim/` — GDScript port of the pure TS sim as `RefCounted` classes
  (no Node, no wall-clock, no `randf()`). `dt` is REAL seconds everywhere;
  convert to game hours only via `Config.TIME.REAL_SECONDS_PER_GAME_HOUR` (30).
  - `config.gd` `rng.gd` (mulberry32, bit-exact) `noise.gd` `terrain.gd`
    `needs.gd` `items.gd` `fire.gd` `scatter.gd` `interact.gd` `shelter.gd`
    `rescue.gd` `world.gd` (step ordering mirrors `world.ts`) `actions.gd`
    `dangers.gd` (snares/fishing/injuries; wolf FSM deliberately unported)
    `craft.gd` (recipe table + canCraft/craft, port of craft.ts) `build.gd` `player.gd`
- `tests/` — headless SceneTree tests (`run_tests.sh` convention).
  `goldens.gd` holds reference values extracted from the real TS sim
  (regenerate: `node tools/extract_goldens.mjs` against a copy of `src/sim/*.ts`).
  Golden floats are stored as IEEE-754 bit patterns and rebuilt with `Goldens.f()`
  because GDScript's 17-digit decimal literal parsing is ~1 ULP off V8's.
- `scenes/main.tscn` — generated by `tools/gen_scene.gd` (never hand-edited).
- `src/render/terrain_mesh.gd` — 128×128 ArrayMesh sampled from the frozen
  `Terrain.heightAt` (vertex colors: snow/rock/stream/lake-ice; flat shading
  via omitted normals). No new height math.
- `src/render/scatter.gd` — the frozen `Scatter.scatter()` props instanced as
  one MultiMeshInstance3D per glTF model (Pine/CommonTree/Rock variants picked
  deterministically by prop index); Y from `heightAt`.
- `assets/nature/` — Stylized Nature MegaKit (Quaternius, CC0) glTF subset:
  Pine_1–3, CommonTree_1–2, Rock_Medium_1–2, DeadTree_1 + sidecar PNGs, flat
  (per docs/asset-inventory.md recipe). License_Standard.txt kept alongside.
- `vendor/sdk/` — vendored copies of `sdk/prefabs/player_mover.gd` +
  `camera_third_person.gd` (see `vendor/sdk/VENDOR.md`). Player spawns at the
  sim's `Terrain.CRASH` site; WASD + mouse-look (input map in project.godot).
- `src/game/game.gd` — `GameLoop`: owns the `WorldSim`, fixed-step accumulator
  (0.25 s REAL ticks; dt stays real seconds — the #1 historical bug class),
  syncs the 3D rig into `world.player`, harvests sim-log lines into `toasts`.
  `setup()` is restart-safe (re-creates the world and clears toasts/tick
  counters). Actions: E interact (collect a sprung snare in reach, else
  chop/snap/peel/scoop/snow/scavenge via the frozen `Interact` radius), F feed
  fire, R melt, C cook, Q drink, T eat, X set snare (TS setSnareAction rules
  incl. the 8 m too-close check), G fish an ice-edge hole, B craft the first
  craftable recipe (TS craftBest greedy order), H treat wound (duct tape + lit
  fire).
- `src/game/game_state.gd` — `GameState`: the framing machine
  MENU -> PLAYING -> WON / DEAD. Watches `world.rescued` / `world.dead` on
  every sim tick (only while PLAYING), pauses the sim outside PLAYING, and
  restarts by re-creating the world from the SAME seed through an optional
  `rebuild` hook (main.gd re-applies terrain provider, camp fire, player seat)
  — no process restart.
- `src/render/game_ui.gd` — `GameUi`: title / win / death screens, code-built
  CanvasLayer (dim rect + centered labels). ENTER or left-click emits
  start/restart. Title shows BOREAL + controls; death shows cause + days
  survived; win shows rescued-on-day-N + days survived.
- `src/game/camp_site.gd` — grid-samples the frozen `heightAt` near CRASH and
  picks the flattest fire-ring spot (test asserts footprint max−min < 0.15 m);
  the sim's CRASH position itself is untouched.
- `src/game/player_rig.gd` + `src/render/camp_visuals.gd` — code-built player
  capsule rig and camp (trodden pad + rock ring + shadowless warm omni +
  emissive flame; the old shadowed 20-energy omni painted pink streaks).
- `src/render/water.gd` — stream ribbon following `Terrain.streamX`, riding the
  frozen channel-floor formula; wave/fresnel/foam shader. `SHOT_FROZEN=1` pins
  `u_time` (deterministic shots; live play uses sim seconds, never wall-clock).
- `src/render/day_night.gd` — sun angle, sky gradient, fog, ambient as a pure
  function of the sim's `hourOfDay`.
- `src/render/hud.gd` — needs bars, core/feels temp, day+clock, inventory,
  context prompt (TS contextActions tier order: snare collect > fish hole >
  gather target), injury/infection status line when wounded ([H] hint on
  treatable wounds), toasts (tick-timed expiry, no wall-clock).
- `src/render/snare_markers.gd` — stake + noose-loop marker at every set
  snare (code-built meshes, 2 shared materials); a red bundle appears at the
  snare when it holds pending game (the pickup marker).
- `src/render/wreck_visuals.gd` — `WreckVisuals`: the crash-site plane wreck
  (DeJunes low-poly Cessna FBX, `assets/wreck/`, royalty-free — see
  `assets/wreck/LICENSE.txt`). Normalized at runtime from its merged vertex
  AABB (the FBX carries messy Blender export scales), posed nose-toward-camp
  + pitch/roll/sink, placed at `Terrain.CRASH` (analytic) and baked
  spawn+(6,-6) (generated) — exactly where the sim's wreck interactable
  sits on each level. NO material_overlay tint: the mesh has no vertex
  colors (white-tree lesson).
- `src/audio/audio_map.gd` — `AudioMap`: the PURE sim-state → sound mapping
  (static functions, no Node/audio APIs, headless-testable). `map_state(dict)`
  → `{loops: {fire_crackle|wind_loop: vol}, step_interval, step_vol}`;
  `from_world(w, game_state)` extracts fire warmth, windKmh (storm-multiplied),
  storm severity, speed and zone from the frozen sim. Wolves are CUT, so no
  growl mapping (owner directive).
- `src/audio/audio_director.gd` — `AudioDirector`: consumes GameLoop state on
  every sim tick. Runtime-created Master/Ambience/SFX buses, two loop players
  (fire crackle volume = warmth at player; wind bed volume from windKmh,
  smoothed attack/release), footstep cadence on the sim-tick accumulator
  (interval from speed, volume from zone, 5 rotating variants — no randf),
  and event one-shots: UI confirm on every action key, rescue plane flyby on
  WON, death sting on DEAD (`GameState.state_changed`). All playback is
  guarded behind a non-headless check; the mapping still runs headless.
- `assets/audio/` — 10 CC0 OGGs (OGA fireplace/wind/propeller/game-over/menu-
  tick + Kenney RPG footstep variants), provenance in `assets/audio/LICENSE.txt`.
- `levels/gen_001/` — **second level: baked terrain-gen world** (seed 1337,
  256², cell 2 m; heights/biomes/meta/spawn JSONs + mesh/collision `.tres`).
  Reproduce with `bash tools/gen_level.sh` — the baked files are the
  determinism boundary; never regenerate casually.
- `src/level/terrain_hm.gd` — `TerrainHM`: heightmap adapter over the baked
  grid (bilinear `heightAt` for render, nearest-cell `heightAtCell` for
  gameplay, `zoneAt`/`speedMulAt` duck-typed against the frozen `Terrain`,
  plus nearest-water BFS + `stream_info`). Adapter only — `src/sim/` untouched.
- `src/level/gen_content.gd` — `GenContent`: deterministic biome-driven scatter
  (forest→spruce/birch, rock→rocks, seeded jitter, camp clearing kept clear)
  and the water-cell rect decomposition feeding the lake quads.
- `src/level/gen_level.gd` — `GenLevel`: glue — loads baked mesh/collision,
  builds scatter + flat lake quads (water shader reused), and injects
  baked-world data into the frozen sim (spawn pose, colliders, interactables,
  water scoop points). `GameLoop.terrain` is the provider seam (default =
  frozen `Terrain`); `LEVEL=generated` swaps in `TerrainHM` from `main.gd`.

## Run
```bash
# from the repo root (this repo IS the Godot project — open it in the editor, or:)
bash scripts/run_tests.sh .                       # semantic tests, no pixels
bash scripts/render_shot.sh . /tmp/boreal.png     # headless shot (weston + Vulkan; NixOS notes in docs/rendering.md)
# curated viewpoints: camp | treeline | stream | hud (default: follow player);
# framing screens: menu | dead | won (SHOT_FROZEN=1 for deterministic shots).
# SHOT_FROZEN=1 pauses the sim + pins water time for deterministic shots.
CHECKPOINT=camp SHOT_FROZEN=1 bash scripts/render_shot.sh . /tmp/camp.png
# second level (baked terrain-gen world): LEVEL=generated swaps terrain,
# scatter, water and spawn; checkpoints camp | water | overview.
LEVEL=generated CHECKPOINT=overview SHOT_FROZEN=1 \
  bash scripts/render_shot.sh . shots/gen_overview.png
godot --headless --path . --script res://tools/gen_scene.gd  # regen main.tscn
```

## Play the web build
The itch-ready artifact is `dist/boreal-web-<ver>.zip` (index.html at zip
root — itch.io's requirement). Rebuild it with:
```bash
export PATH=$HOME/.local/bin:$PATH          # godot lives in ~/.local/bin
bash tools/export.sh                        # -> dist/web/ + dist/boreal-web-0.1.0.zip
VER=0.2.0 bash tools/export.sh              # override the version stamp
```
Requirements: the **Web export templates** for the engine version installed
under `~/.local/share/godot/export_templates/<ver>.stable/` (this host:
`4.7.2.stable`, matching `godot --version` = `4.7.2.stable.nixpkgs.*`;
download `web_*.zip` from the matching GitHub release). The preset
(`export_presets.cfg`) exports **without threads** (`variant/thread_support=
false`): itch.io serves plain files without COOP/COEP headers, which
threaded Godot web builds require — no-threads is the itch-compatible
choice. Web uses `gl_compatibility` (`project.godot`
`renderer/rendering_method.web`); desktop keeps `forward_plus`.

Smoke-test the exported build headlessly (no GPU needed; nixpkgs Chromium +
python playwright via nix-shell):
```bash
TMPDIR=/tmp nix-shell -p python3Packages.playwright --run \
  'TMPDIR=/tmp python3 tools/smoke_web.py dist/web $(which chromium)'
```
It serves `dist/web/` on localhost and asserts: wasm/pck fetched 200, the
splash overlay removed (= `startGame()` resolved), canvas 1280×720 with a
live WebGL2 context, non-uniform framebuffer (real frames rendered), no
page errors. Prints `SMOKE: PASS/FAIL`.

**Level default:** the web build ships the **frozen analytic terrain** as
the MVP default level — it matches the TS reference balance the harness was
tuned against. The baked terrain-gen level stays opt-in: `LEVEL=generated`
(env) swaps in `TerrainHM`; it is not selectable in the itch build.

### itch.io page copy (draft)
> **BOREAL** — a solo survival. You are the only survivor of a small-plane
> crash in a frozen wilderness. The radio is dead; search passes fly the
> area around day 7. There are no wolves, no monsters, no scripted
> encounters — just cold, hunger, thirst, and sleep, and the slow arithmetic
> of staying ahead of all four. Chop wood and keep the fire from sinking,
> scoop snow and melt it, set snares on hare signs, fish the ice edge,
> craft what you can carry. Eat and your body stores it; starve and it
> burns mass — past 60 kg the cold finishes the job. Push too many days
> without sleep and your hands stop working. Survive to the dawn of day 7
> and flag down a pass. Deterministic survival sim (seeded, no RNG you
> can't reason about), ported value-for-value from a tested TypeScript
> reference. WASD + mouse, keyboard actions; runs in your browser.

## Handover notes (generated level, 2026-10-08)
- **White trees — fixed.** `ScatterRender.make_multimesh(..., material_overlay)`
  replaces the surface material outright; the Quaternius glTF meshes carry no
  vertex colors, so the unshaded snow-tint material rendered every prop as a
  flat white silhouette. Generated-level scatter now uses the glTF materials
  as-is (like the frozen level). Do NOT reintroduce a tint overlay on meshes
  without vertex colors.
- **Fog wash, not a bug.** Distant trees/terrain bleach toward the fog color
  (`day_night.gd` fog ≈ horizon color, density 0.005–0.008). The blue-gray
  near-ground tint is identical on the default level — pixel-sampled, matches
  the frozen baseline. If a reviewer says "everything is white/blue", check
  against `shots/boreal_camp.png` before chasing it.
- **Known v0 gaps (generated level):** lake quads are axis-aligned rects
  (stair-stepped shorelines by design); the frozen sim's zone/wind math still
  reads analytic `Terrain` internally (sim-freeze constraint), so generated
  zone effects are approximate; checkpoint cams are hardcoded offsets from
  the baked spawn.
- **Env trap:** `godot` + `weston` live in `~/.local/bin` (symlinks into
  nixpkgs godot-4.7.2 / weston-15). A fresh shell without that on PATH makes
  every test fail with exit 127 — that is NOT a code regression.
- **Never regenerate `levels/gen_001/` casually** — baked files are the
  determinism boundary (`height_hash ebabe3cf` pinned in tests).
