# boreal (Godot port) — phase 1

Standalone Godot 4.7.1 port of the BOREAL survival sim (`boreal-src/` TypeScript).
**Phase 1 = pure sim core + analytic terrain, golden-value tested. No gameplay
UI, no wolves/snares/fishing (phase 2 stubs), placeholder 3D scene.**

## Layout
- `src/sim/` — GDScript port of the pure TS sim as `RefCounted` classes
  (no Node, no wall-clock, no `randf()`). `dt` is REAL seconds everywhere;
  convert to game hours only via `Config.TIME.REAL_SECONDS_PER_GAME_HOUR` (30).
  - `config.gd` `rng.gd` (mulberry32, bit-exact) `noise.gd` `terrain.gd`
    `needs.gd` `items.gd` `fire.gd` `scatter.gd` `interact.gd` `shelter.gd`
    `rescue.gd` `world.gd` (step ordering mirrors `world.ts`) `actions.gd`
    `build.gd` `player.gd`
- `tests/` — headless SceneTree tests (`run_tests.sh` convention).
  `goldens.gd` holds reference values extracted from the real TS sim
  (regenerate: `node tools/extract_goldens.mjs` against a copy of `src/sim/*.ts`).
  Golden floats are stored as IEEE-754 bit patterns and rebuilt with `Goldens.f()`
  because GDScript's 17-digit decimal literal parsing is ~1 ULP off V8's.
- `scenes/main.tscn` — generated by `tools/gen_scene.gd` (never hand-edited);
  placeholder terrain mesh sampled from the same `heightAt` the sim uses.

## Run
```bash
# from the godot-factory repo root
bash scripts/run_tests.sh games/boreal            # semantic tests, no pixels
bash scripts/render_shot.sh games/boreal /tmp/boreal.png   # weston+lavapipe shot
godot --headless --path games/boreal --script res://tools/gen_scene.gd  # regen main.tscn
```

## Test status (phase 1)
- `test_rng.gd` — mulberry32 + `roll()` seed mix bit-exact vs TS (7 seeds × 20 outputs + raw u32 path)
- `test_terrain.gd` — hash2/valueNoise2/fbm2 bit-exact; heightAt/zoneAt/streamX ±1e-9 (libm drift allowance)
- `test_needs.gd` — windchill/airTemp/heatBudget goldens + all TS tuning-target tests (walking @ feels −25 ≈ stable, idle @ −20 → hypothermia 3–7 h, fire rescue, soaked crisis, shelter gain, food=fuel, death chains, auto-sip)
- `test_world.gd` — 2-game-day determinism (state hash ×2, seed divergence), feed-fire/melt/cook/scavenge/sleep happy paths
